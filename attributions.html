Attributions

Every Cinema London is a showcase built on data and services generously provided by others. Thank you to the following.

Screening data — Clusterflick

Cinema listings and showtimes (performances, venues, formats and accessibility details) are compiled by Clusterflick, which aggregates what’s on across London’s cinemas and venues.

This project uses the published combined dataset from github.com/clusterflick/data-combined.

The venue-health page is built from Clusterflick’s hourly listing checks, published a day at a time as releases on github.com/clusterflick/data-analysed.

Screening data from Clusterflick is published under CC BY 4.0, per its data licence.

What we’ve changed

CC BY 4.0 asks that changes be stated, and this site makes plenty of them. Nothing here is a verbatim copy of a Clusterflick release.

  • The showtimes grid ships a compacted, denormalised blob — lookups extracted, movie fields stored once per movie, performances reduced to id-referencing records — and expands it back into rows in the browser.
  • Screening history is reconstructed rather than republished. A release lists only future performances, so the record of what actually screened is assembled by partitioning consecutive releases into windows and bucketing each window’s performances by hour.
  • Venue health aggregates the hourly check log into per-day, per-venue rates, and adds scoring Clusterflick does not publish — deciding which outcomes count for or against a venue’s uptime, and leaving checks inside a declared closure out of the rate entirely.

The CC BY 4.0 grant covers the screening data — performances, venues, booking links, formats and accessibility. It does not cover the film metadata shown alongside it in the same rows: posters, genres, certificates, runtimes and directors come from TMDB under separate terms, below.

Film metadata — The Movie Database (TMDB)

Film metadata — titles, posters, genres, classifications, runtimes and directors — is sourced from The Movie Database (TMDB).

This product uses the TMDB API but is not endorsed or certified by TMDB.

Grid — AG Grid

The interactive data grid is AG Grid (Enterprise), used here to demonstrate row grouping, pivoting and filtering over the dataset.

Charts — AG Charts

The charts on the screening history page are AG Charts (Community), plotting daily screening counts and per-film runs built from Clusterflick’s release history.
